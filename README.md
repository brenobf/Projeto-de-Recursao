# Como executar o projeto

## 1. Requisitos

Antes de executar o projeto, é necessário ter instalado:

- Python 3.
- Visual Studio Code (opcional, caso queira utilizar o VS Code).

Não é necessário instalar bibliotecas externas, pois o projeto utiliza módulos que já acompanham o Python, como `tkinter`, `time` e `turtle`.

## 2. Verificar a instalação do Python

Abra o terminal e execute:

```bash
python --version
```

Caso o comando não funcione, tente:

```bash
py --version
```

Se aparecer a versão instalada do Python, ele está pronto para uso.

## 3. Executar o projeto

No Visual Studio Code, abra o terminal pelo menu **Terminal → Novo Terminal**.

Certifique-se de que o terminal está na pasta onde se encontra o arquivo `projeto.py`.

Execute o seguinte comando:

```bash
python projeto.py
```

Se necessário, utilize:

```bash
py projeto.py
```

## 4. Inicialização

Após executar o comando:

1. O programa realizará automaticamente os testes dos algoritmos.
2. Se todos os testes forem aprovados, aparecerá a mensagem `Todos os testes passaram!` no terminal.
3. Em seguida, a interface gráfica será aberta.

**Observação:** Para utilizar a visualização da árvore fractal, o projeto também precisa conseguir abrir uma janela gráfica pelo módulo `turtle`.**
